# How to put this project on GitHub (no coding needed)

You can delete this file from the folder before uploading if you want.

1. **Make an account.** Go to github.com and sign up. Pick a professional username (like your name).
2. **Make a new repository** ("repo" = a project folder online).
   - Click the **+** in the top right → **New repository**.
   - Name: `cpt-international-students`
   - Choose **Public**.
   - Do NOT tick "Add a README" (you already have one).
   - Click **Create repository**.
3. **Upload the files.**
   - On the new page, click the link **"uploading an existing file"**.
   - Unzip the project on your laptop. Drag in everything **inside** the `cpt-project` folder:
     `README.md`, `analysis.py`, and the `data` and `charts` folders.
   - Scroll down, type a message like `First version`, and click **Commit changes**.
4. **Check it.** Refresh the page. Your README shows up with the charts in it.
5. **Copy the link** (it looks like `github.com/yourname/cpt-international-students`).
   Put it on your resume and in your transfer application's activities section.

Tip: if dragging folders doesn't work in your browser, open the `data` and `charts` folders and drag the
files inside them. GitHub will ask you to keep the folder names, or you can type `data/` before the file name.
